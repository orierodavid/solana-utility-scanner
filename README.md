# Solana Utility Scanner

An AI-powered Solana Utility Token Alpha Engine designed to discover high-potential utility tokens before they become widely recognized.

## Objective

Identify newly launched or emerging Solana utility tokens with strong short-term momentum while filtering out low-quality projects and scams.

## Core Features

- Utility Token Detection
- AI-Powered Token Analysis
- Alpha Scoring Engine
- Risk Assessment
- Market Cap Analysis
- Liquidity Analysis
- Holder Growth Analysis
- Volume Spike Detection
- Catalyst Detection
- Smart Money Tracking
- AI Trade Recommendation
- Automated Notifications

## AI Decision Model

Every token receives an Alpha Score from **0–100**.

| Score | Status |
|--------|--------|
| 90–100 | High Conviction Trade Candidate |
| 85–89 | Trade Candidate |
| 75–84 | Wait for Confirmation |
| Below 75 | No Trade |

A token must also satisfy mandatory risk rules before being classified as a Trade Candidate.
